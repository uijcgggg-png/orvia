# Orvia
Chat: https://uijcgggg-png.github.io/orvia/
- `orvia-companion.apk` Android companion (debug-signed). Built from `android-source.zip` with JDK 17 + Gradle 8.7 + Android SDK 34.
- `orvia-companion-windows.py` + `run-orvia-windows.bat` Windows companion (needs Python 3).
- `companion-setup.sql` Supabase tables/functions for device linking (already applied).
No secrets are stored in this repo. The Supabase publishable key is public by design.
